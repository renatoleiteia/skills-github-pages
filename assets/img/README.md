## Especificação técnica

- **Formato:** `.jpg` para fotos (qualidade 78–85) ou `.webp` para 30–40% menos peso.
- **Largura:** 1600–1920 px nas imagens largas; 1200 px nas verticais de serviço.
- **Peso-alvo:** até 250 KB por imagem; o poster do hero, até 350 KB.
- **Tratamento:** o site é escuro. Prefira imagens com sombras profundas e um
  ponto de luz — fotos "estouradas" de fundo branco brigam com o layout.
